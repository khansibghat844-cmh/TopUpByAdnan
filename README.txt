ADNANTOPUPSHOP — QUICK START

FILES
- index.html : website content
- style.css  : black and gold responsive design
- script.js  : product list, prices, filters, WhatsApp ordering

BEFORE PUBLISHING
1. Open script.js.
2. Confirm WHATSAPP_NUMBER is correct (country code + number, digits only).
3. Edit the sample prices in the products array to your real prices.
4. Test every order button on your phone.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a GitHub account: https://github.com/
2. Create a NEW PUBLIC repository named adnantopupshop (or another name you prefer).
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes. GitHub will show the published website URL in Settings > Pages.

NOTES
- Do not upload passwords, API keys, private customer information, or payment secrets into this public repository.
- This is a front-end demo with WhatsApp ordering, not automatic payment or automatic top-up delivery.
- Confirm current hosting terms and account requirements on GitHub Pages before publishing.
- Prices are examples; verify and change them before making the site public.
